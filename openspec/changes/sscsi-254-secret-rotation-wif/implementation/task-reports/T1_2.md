## Findings

### Q3 — Per-resource custom AssetFunc: CONFIRMED (via composite pattern)

**`WithConditionalResources` signature:**
```go
func (c *StaticResourceController) WithConditionalResources(
    manifests resourceapply.AssetFunc,
    files []string,
    shouldCreateFnArg, shouldDeleteFnArg resourceapply.ConditionalFunction,
) *StaticResourceController
```

Each call to `WithConditionalResources` takes its own `AssetFunc`. The controller stores multiple file groups, each with their own asset function.

**`CSIControllerSet.WithConditionalStaticResourcesController`** passes ONE `AssetFunc` for all files in the list.

### Current Wiring

`csidriver.yaml` is currently in the `files []string` passed to `WithConditionalStaticResourcesController` with `replaceNamespaceFunc(operatorNamespace)` as the AssetFunc:

```go
replaceNamespaceFunc(operatorNamespace) = func(name string) ([]byte, error) {
    content, err := assets.ReadFile(name)  // reads from embedded FS
    return bytes.ReplaceAll(content, []byte(namespaceKey), []byte(namespace)), nil
}
```

`csidriver.yaml` is cluster-scoped — no namespace replacement needed for it (but the function applies uniformly).

## T1_4 Wiring Decision

**Selected approach: Composite AssetFunc (no library-go changes needed)**

Replace `replaceNamespaceFunc(operatorNamespace)` in the existing `WithConditionalStaticResourcesController` call with a new `makeAssetFunc(clusterCSIDriver, operatorNamespace)`:

```go
func makeAssetFunc(clusterCSIDriver *opv1.ClusterCSIDriver, namespace string) resourceapply.AssetFunc {
    return func(name string) ([]byte, error) {
        if name == "csidriver.yaml" {
            return generateCSIDriverBytes(clusterCSIDriver)
        }
        // All other assets use static read + namespace replacement
        content, err := assets.ReadFile(name)
        if err != nil {
            panic(err)
        }
        return bytes.ReplaceAll(content, []byte(namespaceKey), []byte(namespace)), nil
    }
}
```

`csidriver.yaml` stays in the existing files list. No new controller instance needed. No library-go changes.

**Why this is the right approach:**
- Single point of change in `starter.go`
- The composite AssetFunc is testable in isolation
- `csidriver.yaml` must be conditional on Managed state (already handled by the existing `shouldCreateFn`/`shouldDeleteFn`)
- Matches the existing namespace-replacement pattern for all other assets
