### Changes Made

**1. Lister construction** (new line before `csiControllerSet`):
```go
clusterCSIDriverLister := dynamicInformers.ForResource(gvr).Lister()
```

`dynamicInformers` is the `dynamicinformer.DynamicSharedInformerFactory` returned by `NewClusterScopedOperatorClientWithConfigName`. `gvr` is the `ClusterCSIDriver` GVR already in scope. `.ForResource(gvr).Lister()` returns a `cache.GenericLister` backed by the informer's cache — no new client or informer instantiated.

## ADR-001 Adherence

T2_1 documented ADR-001: `withSecretRotationHook` accepts `cache.GenericLister` rather than `operatorClient` (tasks.md originally stated `withSecretRotationHook(operatorClient)`). T2_2 wires it correctly using `clusterCSIDriverLister` sourced from `dynamicInformers.ForResource(gvr).Lister()`.

## Hook Ordering

`WithCABundleDaemonSetHook` remains first per Principle VIII (library-go CA bundle hooks must precede operator-specific mutations). Rotation hook runs after CA bundle mutation on each DaemonSet reconcile.
