### New Functions Added

**`csiDriverAssetFunc(lister cache.GenericLister, namespace string) resourceapply.AssetFunc`**  
Composite AssetFunc. Dispatches `"csidriver.yaml"` to `generateCSIDriverBytes`; all other assets fall through to static file + namespace substitution (same behaviour as `replaceNamespaceFunc`). T1_4 replaces `replaceNamespaceFunc` in `WithConditionalStaticResourcesController` with this function.

**`generateCSIDriverBytes(lister cache.GenericLister) ([]byte, error)`**  
Core generation function. Reads static `csidriver.yaml` baseline via `assets.ReadFile` → `resourceread.ReadCSIDriverV1OrDie`. Fetches `ClusterCSIDriver` via lister. Applies two conditional spec mutations:
- `spec.requiresRepublish = true` when `SecretRotation.Type == Custom`
- `spec.tokenRequests` from `TokenRequests.Managed.Audiences` when `TokenRequests.Type == Managed`

Then sets `TypeMeta` and returns JSON bytes for `ReadGenericWithUnstructured`.

**`makeCSIDriverTokenRequests(audiences *[]opv1.SecretsStoreTokenRequest) []storagev1.TokenRequest`**  
Converts operator API `SecretsStoreTokenRequest{Audience *string, ExpirationSeconds int32}` to k8s `storagev1.TokenRequest{Audience string, ExpirationSeconds *int64}`.

## Behavior Contract Implemented

| Scenario | `requiresRepublish` | `tokenRequests` |
|----------|---------------------|-----------------|
| `driverType` ≠ SecretsStore | nil (omit) | nil (omit) |
| `SecretRotation.Type = None` | nil (omit, matches static baseline) | — |
| `SecretRotation.Type = Custom` | `true` | — |
| `TokenRequests.Type = Managed` | — | populated from audiences |
| `TokenRequests.Type = Unmanaged` | — | nil (spec-hash stable → FR-005) |
| ClusterCSIDriver not found | nil | nil (static baseline returned) |

## Serialization

- Input: `assets.ReadFile("csidriver.yaml")` → `*storagev1.CSIDriver` via `ReadCSIDriverV1OrDie`  
- Output: `encoding/json.Marshal(*storagev1.CSIDriver)` with `TypeMeta{APIVersion: "storage.k8s.io/v1", Kind: "CSIDriver"}` explicitly set  
- The returned JSON bytes are decoded by `ReadGenericWithUnstructured` via `api.InstallKube(genericScheme)` which includes `storage.k8s.io/v1`

## FR-005 Design Note (Unmanaged hash stability)

`ApplyCSIDriver` stores a spec-hash annotation (`"operator.openshift.io/spec-hash"`) computed from the **required** object's spec. When `TokenRequests.Type = Unmanaged`, `tokenRequests` is omitted from the generated bytes, making the hash stable across reconcile loops. Any manually added `tokenRequests` on the live object do not affect the operator-written hash annotation, so `ApplyCSIDriver` does not trigger a recreate — preserving the admin-managed `tokenRequests` value as specified by FR-005.
