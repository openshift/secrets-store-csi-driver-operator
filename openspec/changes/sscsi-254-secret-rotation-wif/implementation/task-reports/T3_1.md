## Design Notes

**Why `wantTokenRequestsLen = -1` for nil-expect**: A sentinel value of `-1` distinguishes "expect nil" from "expect 0 length", since both nil and empty-slice produce identical JSON after `omitempty` round-trip. The test checks `TokenRequests != nil` vs `len(TokenRequests) != tc.want`.

**Why real indexer**: Using `cache.NewGenericLister` with a real indexer (vs a fake struct) avoids maintaining a custom interface stub and ensures the Not-Found error path produces a real `apierrors.IsNotFound` error as it would in production.
