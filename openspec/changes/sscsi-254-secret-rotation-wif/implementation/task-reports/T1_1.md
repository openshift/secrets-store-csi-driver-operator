**File:** `vendor/github.com/openshift/library-go/pkg/operator/resource/resourceapply/storage.go` line 141

**Signature:**
```go
func ApplyCSIDriver(
    ctx context.Context,
    client storageclientv1.CSIDriversGetter,
    recorder events.Recorder,
    requiredOriginal *storagev1.CSIDriver,
) (*storagev1.CSIDriver, bool, error)
```

**Behavior:**
- On first run (object absent): calls `Create` with `WithCleanLabelsAndAnnotations(required)` — only annotations/labels explicitly in `required` are persisted
- On subsequent runs: spec-hash comparison via `SetSpecHashAnnotation`; if spec changed → Delete+Create; if metadata only → Update
- Metadata update path: `EnsureObjectMeta` → `MergeMap` for annotations → **MERGES** (adds required keys, preserves existing)

### Annotation Handling — `csi.openshift.io/managed: "true"`

**MUST be in the generated bytes.** At creation time, `WithCleanLabelsAndAnnotations` strips annotations not explicitly present in the required object. The current static `csidriver.yaml` already carries this annotation:
```yaml
annotations:
  csi.openshift.io/managed: "true"
```
T1_3's `csiDriverAssetFunc` must preserve this annotation in the generated YAML bytes.

### Required Label Validation

`validateRequiredCSIDriverLabels` enforces: if `spec.volumeLifecycleModes` includes `Ephemeral`, the label `security.openshift.io/csi-ephemeral-volume-profile` must be present. Current `csidriver.yaml` already has `"restricted"`. T1_3 must carry this label.

## Handoff to T1_3

**T1_3 implementation approach:** Use `ApplyCSIDriver` directly (NOT generic unstructured). The function is present and well-suited for this use case.

**`csiDriverAssetFunc` contract:**
1. Parse static `csidriver.yaml` bytes as the base `*storagev1.CSIDriver`
2. Conditionally set `spec.requiresRepublish = true` if `secretRotation.type == "Custom"`
3. Conditionally set `spec.tokenRequests` if `tokenRequests.type == "Managed"`
4. Serialize back to YAML bytes
5. The caller (StaticResourceController) will pass these bytes to `ApplyCSIDriver`
