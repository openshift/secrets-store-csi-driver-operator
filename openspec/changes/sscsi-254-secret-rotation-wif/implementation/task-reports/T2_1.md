
### `withSecretRotationHook(clusterCSIDriverLister cache.GenericLister) DaemonSetHookFunc`

Reads the live `ClusterCSIDriver` from the informer lister, converts from `*unstructured.Unstructured` to `*opv1.ClusterCSIDriver`, then calls `applySecretRotationArgs` on the `"csi-driver"` container.

- `SecretRotationNone` → `--enable-secret-rotation=false`
- `SecretRotationCustom` + `RotationPollIntervalSeconds > 0` → `--enable-secret-rotation=true --rotation-poll-interval=<Ns>`
- `SecretRotationCustom` + no interval → `--enable-secret-rotation=true --rotation-poll-interval=2m` (FR-003 default)
- Empty/unset type → no mutation (upgrade no-op, FR-003)

### `applySecretRotationArgs` and `removeRotationArgs`

Helper functions: `removeRotationArgs` strips existing rotation args for idempotency; `applySecretRotationArgs` applies the new values based on `SecretRotationType`.
